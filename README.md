Esta é uma versão modificada do tema [Xenlism GRUB themes](https://github.com/xenlism/Grub-themes), adaptada com foco em telas **Full HD (1080p)** e com paleta e elementos visuais customizados para o **Fedora Red**.

---

## 🛠️ Modificações Realizadas

- 🎨 **Ajustes de Design:** Customização visual com tons vermelhos alinhados ao estilo Fedora Red.
- 📐 **Resolução 1080p:** Otimização do layout e fontes para exibições Full HD (1920x1080).
- 🧹 **Limpeza do Repositório:** Remoção de diretórios/recursos desnecessários para um pacote mais leve e direto.
